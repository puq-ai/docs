# Workflow Apps

A **Workflow App** gives a workflow its own simple page — an input form, a Run button, and a result — at `puq.ai/apps/<slug>`, so it can be used without opening the Visual Builder. In the sidebar this feature is labeled **Apps**.

| | Browse Apps (public) | My Apps (yours) |
|---|---|---|
| Published by | puq.ai | You, from one of your own workflows |
| Visible to | Anyone | Only you |
| Account needed to | Run it | Browse, run, and manage it |
