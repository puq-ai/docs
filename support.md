# Support

Open **Support** from the sidebar (`/support`) for every way to get help with puq.ai.

## Documentation & Resources

The Support page links out to documentation sections for quick access:

- **Getting Started** — create a workspace, add connections, and build your first flow
- **Workflows** — build, publish, debug, and version your flows
- **Executions** — monitor workflow runs, inspect node outputs, debug failures
- **API Reference** — generate API tokens, invoke published flows, integrate externally
- **Data & Connections** — pass data between nodes, map parameters, connect services
- **Integrations** — browse all available integrations at [puq.ai/integrations](https://puq.ai/integrations)

## Join the Community

- **Discord** — real-time chat and support: [discord.com/invite/8rfzMgutga](https://discord.com/invite/8rfzMgutga)
- **Reddit** — community discussions: [reddit.com/r/puq](https://www.reddit.com/r/puq/)

## Contact Support

- **Email Support** — typically replies within 24 hours. Click **Send Email** to open a message
  addressed to `support@puq.ai`.
- **WhatsApp Support** — shown to users in Turkey, for quick, personalized support.

## Feedback

Use **Send Feedback** on the Support page to share ideas or report issues directly, or join the
[Community Forum](https://community.puq.ai) for open discussion.
